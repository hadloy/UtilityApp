## 22 September 2026

### Git and GitHub Setup

I learned the basic difference between Git and GitHub.

- Git tracks changes in my project locally.
- GitHub stores the repository online.
- A commit creates a saved checkpoint of my project.
- A push sends my local commits to GitHub.
- A pull brings changes from GitHub back to my computer.

I created a private GitHub repository for my CP5307 Utility App and connected it to Android Studio.

I also created my first commits, including the initial project setup and README documentation.

### Project Organisation

I learned how to switch Android Studio from the Android view to the Project view so I can see the real project folder structure.

I created a README.md file at the top level of the project.

I also learned that project files should be committed regularly instead of waiting until the assignment is finished.
